# KPI Pro by Rajput

Daily KPI Track Report generator for sales distribution agencies.

**Live:** https://talhaali1201.github.io/

## Kya karta hai
- Daily KPI Excel (.xlsx / .xls) upload karo — sheet ka naam kuch bhi ho, `PJP ID` header khud dhund leta hai
- PSR-wise Track Report + SDM-wise summary, Total hamesha Excel file ki apni Total row se
- Green / Yellow / Red target system (Call Completion, Strike Rate, Avg SKU / Order)
- Column picker, SDM mapping (browser me save + Export/Import), Strike Rate ranking
- WhatsApp-ready PNG images (Download / Copy / Share) + saaf Track Excel download
- File browser se bahar kahin upload nahi hoti — 100% private, koi server nahi

## Istemal
1. Live link kholo
2. Apni Daily KPI Excel file click ya drag-drop se upload karo
3. Report, images aur Excel — sab ek click me
